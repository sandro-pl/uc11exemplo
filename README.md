# UC11 — Central de Qualidade

Curso Técnico em Informática.
Unidade Curricular: Executar teste e implantação de aplicativos computacionais.

## Início

Na raiz desta pasta:

    npm install
    npm run exemplos
    npm start

Abra http://127.0.0.1:3333.
O servidor executa o Jest instalado localmente.

Requisitos: Node 20 ou superior, npm, VS Code e Git.
A instalação inicial exige acesso ao registro npm.
O painel e as atividades funcionam localmente após a instalação.

## Percurso de 16 horas

Aula 1: Git, novo repositório, branches, commits e pull requests.
Aula 2: primeiros testes; par ou ímpar, cinema e medidas.
Aula 3: números, fronteiras e regras; temperatura, média e desconto.
Aula 4: arrays, validação, regressão e implantação; tabuada e caixa eletrônico.

Oito missões essenciais, oito atividades de aprofundamento e quatro extras.
As atividades de aprofundamento podem ser distribuídas entre duplas ou usadas como continuidade.

## Estrutura

atividades/: 16 módulos JavaScript com dois defeitos intencionais cada.
extras/: quatro desafios de Promises, mocks, ausência de dados e liberação.
exemplos/: exemplos independentes dos matchers.
guias/: material de Git, Jest e implantação.
painel/: interface de missões.
evidencias/: modelos para entrega.
lib/: validação e execução de testes.
scripts/: preparação da versão local.

O painel registra resultados reais do Jest e evidências.
A avaliação de qualidade considera requisitos, cenários e revisão do professor.
Os arquivos do professor não fazem parte desta distribuição.

## Arquivos iniciais

Os test.todo são lembretes que devem ser substituídos.
As três primeiras missões possuem um teste inicial que revela falhas.
Falhas iniciais são parte do exercício.
